Voir les formules d'incertitudes-types utilisées (moindres carrés ordinaires)

Modèle affine y = a·x + b (avec N ≥ 3 points, N - 2 degrés de liberté) :

• a = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)² et b = ȳ - a·x̄

• Variance résiduelle : s²_{y/x} = [1 / (N - 2)] · Σ(yᵢ - (a·xᵢ + b))²

• Incertitude-type sur la pente : u(a) = √[ s²_{y/x} / Σ(xᵢ - x̄)² ]

• Incertitude-type sur l'ordonnée à l'origine : u(b) = √[ s²_{y/x} · (1/N + x̄² / Σ(xᵢ - x̄)²) ]

Modèle linéaire y = a·x (passage par l'origine, avec N ≥ 2 points, N - 1 degrés de liberté) :

• a = Σ(xᵢ·yᵢ) / Σ(xᵢ²)

• Variance résiduelle : s²_{y/x} = [1 / (N - 1)] · Σ(yᵢ - a·xᵢ)²

• Incertitude-type sur la pente : u(a) = √[ s²_{y/x} / Σ(xᵢ²) ]
