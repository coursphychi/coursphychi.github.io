⚠ Pixels saturés le long du profil : le haut des maxima est écrêté. Réduisez l'exposition (ou l'intensité de la source) avant la prise de vue.
Glissez les curseurs sur le graphique (ou cliquez pour déplacer le plus proche). Pour l'interfrange, placez C₁ et C₂ sur deux maxima séparés de n interfranges ; pour une figure de diffraction, sur les deux minima qui bordent la tache centrale (n = 1 donne alors sa largeur L).
La valeur d'un pixel n'est pas proportionnelle à l'intensité lumineuse (correction gamma de l'appareil, saturation) : seules les positions des extrema sont fiables.
