## Principe d'un titrage {.nt-h2}

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Définition</p>
<p>Les <span class="imp">titrages</span> sont des méthodes de <span class="imp nt-hole">dosage</span> (détermination d'une quantité de matière inconnue) <span class="imp nt-hole">destructive</span> utilisant une <span class="imp nt-hole">transformation chimique</span>.</p>
</div>

<div class="nt-b nt-prop">
<p class="nt-tag"><i class="fa-solid fa-star"></i>À retenir</p>
<p>La <span class="imp">réaction support d'un titrage</span> doit être&nbsp;:</p>
<ul class="nt-facts">
<li><span class="imp nt-hole">totale</span>&nbsp;;</li>
<li><span class="imp nt-hole">rapide</span>&nbsp;;</li>
<li><span class="imp nt-hole">unique</span>.</li>
</ul>
</div>

<div class="nt-b nt-demo-box">
<p class="nt-tag"><i class="fa-solid fa-eye"></i>Remarque</p>
<p>En première, la réaction support du titrage était une <span class="imp nt-hole">oxydoréduction</span>.</p>
</div>

### L'équivalence {.nt-h3}

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Définition</p>
<p>La détermination de la quantité de matière du réactif titré repose sur le repérage de l'<span class="imp nt-hole">équivalence</span>.</p>
</div>

<div class="nt-b nt-demo-box">
<p class="nt-tag"><i class="fa-solid fa-eye"></i>Remarque</p>
<p>En première, le repérage de l'équivalence se fait par <span class="imp nt-hole">suivi colorimétrique</span>.</p>
</div>

<div class="nt-b nt-prop">
<p class="nt-tag"><i class="fa-solid fa-star"></i>À retenir</p>
<ul class="nt-facts">
<li>Avant l'équivalence&nbsp;: <span class="imp nt-hole">le titrant est limitant</span>&nbsp;;</li>
<li>À l'équivalence&nbsp;: il y a <span class="imp nt-hole">changement de réactif limitant</span>&nbsp;;</li>
<li>Après l'équivalence&nbsp;: <span class="imp nt-hole">le titré est limitant</span>.</li>
</ul>
</div>

<p class="nt-lead">Supposons que la réaction support du titrage est $\ce{a A + b B -> \ldots}$, où A est le réactif titré et B est le réactif titrant.</p>

<div class="nt-b nt-ask">
<p class="nt-tag"><i class="fa-solid fa-circle-question"></i>Question</p>
<p>Comment évoluent les quantités de matière dans le mélange réactionnel en fonction du volume de titrant ajouté&nbsp;?</p>
</div>

<div class="nt-lab" id="lab-evol">
<p class="nt-tag"><i class="fa-solid fa-hand-pointer"></i>Animation interactive</p>
<p class="nt-lab-title">Les quantités de matière dans le bécher au cours du titrage</p>
<p class="nt-note">Le bécher contient initialement 1,20&nbsp;mmol de réactif titré A&nbsp;; la burette contient le réactif titrant B à 0,10&nbsp;mol·L<sup>−1</sup>.</p>

<p class="nt-msg" aria-live="polite"></p>
</div>

<div class="nt-b nt-prop">
<p class="nt-tag"><i class="fa-solid fa-star"></i>À retenir</p>
<p>À l'équivalence, le mélange est en <span class="imp nt-hole">proportions stœchiométriques</span>&nbsp;:</p>
</div>

<div class="nt-grid">
<div class="nt-f" style="margin:0 auto;">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>À l'équivalence</p>
<p class="nt-f-math">$$\frac{n_\mathrm{A}}{a}=\frac{n_{\mathrm{B},E}}{b}$$</p>
</div>
<div class="nt-f" style="margin:0 auto;">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Soit, en concentrations</p>
<p class="nt-f-math">$$\frac{C_\mathrm{A} V_\mathrm{A}}{a}=\frac{C_\mathrm{B}\,{\color{#FDE68A}V_E}}{b}$$</p>
</div>
</div>

<div class="nt-b nt-ex">
<p class="nt-tag"><i class="fa-solid fa-lightbulb"></i>Exemple</p>
<p>On titre $V_\mathrm{A} = \pu{10,0 mL}$ d'une solution d'acide chlorhydrique par une solution d'hydroxyde de sodium de concentration $C_\mathrm{B} = \pu{0,100 mol*L-1}$. L'équivalence est obtenue pour $V_E = \pu{12,5 mL}$. Quelle est la concentration $C_\mathrm{A}$ de l'acide&nbsp;?</p>
</div>

<details class="nt-d nt-rep">
<summary><span class="nt-tag"><i class="fa-solid fa-key"></i>Réponse</span><span class="nt-sum">Voir la résolution</span></summary>
<div class="nt-d-body">
<p>La réaction support est $\ce{H3O+ + HO- -> 2 H2O}$&nbsp; ($a = b = 1$).</p>
<p>À l'équivalence, le mélange est en proportions stœchiométriques&nbsp;:</p>
<p class="nt-center">$\displaystyle \frac{n_\mathrm{A}}{1} = \frac{n_{\mathrm{B},E}}{1}$</p>
<p class="nt-center">$\Rightarrow C_\mathrm{A} V_\mathrm{A} = C_\mathrm{B} V_E$</p>
d'où&nbsp;:
<p class="nt-center">$C_\mathrm{A} = \dfrac{C_\mathrm{B}\,V_E}{V_\mathrm{A}} = \dfrac{0{,}100\times 12{,}5}{10{,}0} = \pu{0,125 mol*L-1}$</p>
<p class="nt-note">Les volumes sont dans la même unité au numérateur et au dénominateur&nbsp;: inutile de les convertir en litres.</p>
</div>
</details>

<div class="nt-b nt-proto">
<p class="nt-tag"><i class="fa-solid fa-flask-vial"></i>Protocole d'un titrage colorimétrique</p>
<p class="nt-proto-legend"><span><span class="nt-must">surligné</span>&nbsp;: à écrire sur une copie</span><span class="nt-ece">gestes utiles en TP</span></p>
<ol class="nt-steps">
<li><p><span class="nt-must">Prélever un volume $V_\mathrm{A}$ (par exemple $\pu{10,0 mL}$) de solution titrée à l'aide d'une pipette jaugée</span> et <span class="nt-must">la verser dans un erlenmeyer</span>.</p><p class="nt-ece">Verser au préalable un peu de solution dans un bécher&nbsp;: on ne pipette jamais directement dans le flacon. Rincer la pipette avec un peu de la solution à prélever. Utiliser une propipette (ou une poire)&nbsp;; ajuster le bas du ménisque au trait de jauge, l'œil à sa hauteur, et respecter le ou les traits de jauge en vidant.</p></li>
<li><p><span class="nt-must">Ajouter quelques gouttes d'un indicateur coloré adapté</span> (nommer l'indicateur, et justifier son choix si on le demande).</p></li>
<li><p><span class="nt-must">Remplir la burette graduée avec la solution titrante de concentration $C_\mathrm{B}$ connue, puis ajuster au zéro</span>.</p><p class="nt-ece">Rincer d'abord la burette avec un peu de solution titrante (vidée dans un bécher «&nbsp;poubelle&nbsp;»). La remplir au-dessus du zéro à l'aide d'un petit entonnoir, puis retirer l'entonnoir. Ouvrir le robinet un instant pour chasser la bulle d'air située sous le robinet. Ajuster enfin au zéro, l'œil à hauteur du bas du ménisque.</p></li>
<li><p><span class="nt-must">Placer le récipient sur un agitateur magnétique, avec un turbulent, et agiter</span>.</p><p class="nt-ece">Agitation modérée&nbsp;: pas de projections, pas de tourbillon qui aspire de l'air. Placer une feuille blanche sous l'erlenmeyer pour mieux voir le changement de couleur.</p></li>
<li><p><span class="nt-must">Verser la solution titrante jusqu'au changement de couleur persistant de la solution, et noter le volume versé $V_E$</span>.</p><p class="nt-ece">Faire d'abord un titrage rapide (de millilitre en millilitre) pour encadrer $V_E$. Recommencer ensuite&nbsp;: verser rapidement jusqu'à 1 ou 2&nbsp;mL avant l'équivalence, puis goutte à goutte dès que l'indicateur commence à changer de couleur. Lire le volume au bas du ménisque.</p></li>
</ol>
</div>

<div class="nt-b nt-prop">
<p class="nt-tag"><i class="fa-solid fa-star"></i>À retenir</p>
<p>En terminale, on ajoute les réactions acide-base comme support de titrage et deux types de suivi&nbsp;:</p>
<ul class="nt-facts">
<li><span class="imp nt-hole">pH-métrique</span>&nbsp;;</li>
<li><span class="imp nt-hole">conductimétrique</span>.</li>
</ul>
</div>

<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Définition</p>
<p>La réaction support du titrage est une réaction acide-base et le suivi est pH-métrique (on relève le pH en fonction du volume de titrant ajouté).</p>
</div>

<div class="nt-b nt-proto">
<p class="nt-tag"><i class="fa-solid fa-flask-vial"></i>Protocole d'un titrage pH-métrique</p>
<p class="nt-proto-legend"><span><span class="nt-must">surligné</span>&nbsp;: à écrire sur une copie</span><span class="nt-ece">gestes utiles en TP</span></p>
<ol class="nt-steps">
<li><p><span class="nt-must">Étalonner le pH-mètre</span> à l'aide de solutions tampons.</p><p class="nt-ece">Suivre la notice de l'appareil, en général avec deux solutions tampons (pH 7, puis pH 4 ou pH 10 selon le domaine de pH étudié). <li><p><span class="nt-must">Prélever un volume $V_\mathrm{A}$ (par exemple $\pu{10,0 mL}$) de solution titrée à l'aide d'une pipette jaugée</span> et <span class="nt-must">la verser dans un bécher</span>.</p><p class="nt-ece">Verser au préalable un peu de solution dans un bécher&nbsp;: on ne pipette jamais directement dans le flacon. Ajuster enfin au zéro, l'œil à hauteur du bas du ménisque.</p></li>
<li><p><span class="nt-must">Placer le récipient sur un agitateur magnétique, avec un turbulent, et agiter</span>.</p><p class="nt-ece">Agitation modérée&nbsp;: pas de projections, pas de tourbillon qui aspire de l'air.</p></li>

<li><p><span class="nt-must">Tracer la courbe $\mathrm{pH} = f(V_\mathrm{B})$ et déterminer $V_E$</span> par la méthode des tangentes ou par celle de la dérivée.</p><p class="nt-ece">Reporter les mesures dans un tableau au fur et à mesure (ou directement dans un tableur ou un logiciel d'acquisition). </ol>

<div class="nt-b nt-ask">
<p class="nt-tag"><i class="fa-solid fa-circle-question"></i>Exemple 1</p>
<p>Titrage d'une solution de chlorure de sodium $\ce{(Na+ + Cl^-)}$ par une solution de nitrate d'argent $\ce{(Ag+ + NO3^-)}$. Les ions argent et chlorure précipitent&nbsp;: $\ce{Ag+ + Cl^- -> AgCl(s)}$.</p>
<p>Données&nbsp;: $\lambda_{\mathrm{Na^+}}=\pu{5,0 mS*m^2*mol-1}$&nbsp;; $\lambda_{\mathrm{Cl^-}}=\pu{7,6 mS*m^2*mol-1}$&nbsp;; $\lambda_{\mathrm{Ag^+}}=\pu{6,2 mS*m^2*mol-1}$&nbsp;; $\lambda_{\mathrm{NO_3^-}}=\pu{7,1 mS*m^2*mol-1}$.</p>
<p><b>Prévoir la courbe de titrage obtenue.</b></p>
</div>

<details class="nt-d nt-rep">
<summary><span class="nt-tag"><i class="fa-solid fa-key"></i>Réponse</span><span class="nt-sum">Voir le raisonnement</span></summary>
<div class="nt-d-body">
<p>On suit la quantité de chaque ion dans le bécher (en négligeant la dilution)&nbsp;:</p>
<div class="nt-scroll">
<table class="nt-t nt-t-pente">
<thead><tr><th></th><th>Na<sup>+</sup></th><th>Cl<sup>−</sup></th><th>Ag<sup>+</sup></th><th>NO<sub>3</sub><sup>−</sup></th><th>pente</th></tr></thead>
<tbody>
<tr><th>$V &lt; V_E$</th><td><span class="nt-ar nt-ar-eq">=</span></td><td><span class="nt-ar nt-ar-dn">↘</span></td><td><span class="nt-ar nt-ar-eq">0</span></td><td><span class="nt-ar nt-ar-up">↗</span></td><td><span class="nt-chip nt-chip-m">légèrement négative</span></td></tr>
<tr><th>$V &gt; V_E$</th><td><span class="nt-ar nt-ar-eq">=</span></td><td><span class="nt-ar nt-ar-eq">0</span></td><td><span class="nt-ar nt-ar-up">↗</span></td><td><span class="nt-ar nt-ar-up">↗</span></td><td><span class="nt-chip nt-chip-f">nettement positive</span></td></tr>
</tbody>
</table>
</div>
<p><b>Avant l'équivalence</b>, chaque ion $\ce{Cl^-}$ qui précipite est remplacé dans la solution par un ion $\ce{NO3^-}$ apporté par le titrant. Comme $\lambda_{\mathrm{NO_3^-}} &lt; \lambda_{\mathrm{Cl^-}}$, la conductivité diminue légèrement.</p>
<p><b>Après l'équivalence</b>, il n'y a plus d'ions chlorure&nbsp;: les ions $\ce{Ag+}$ et $\ce{NO3^-}$ ajoutés s'accumulent, la conductivité augmente nettement. La courbe a donc la forme d'un V très dissymétrique.</p>
</div>
</details>

<div class="nt-b nt-ask">
<p class="nt-tag"><i class="fa-solid fa-circle-question"></i>Exemple 2</p>
<p>Titrage d'une solution d'acide éthanoïque $\ce{CH3COOH (aq)}$ par une solution d'hydroxyde de sodium $\ce{(Na+ + HO^-)}$.</p>
<p>Données&nbsp;: $\lambda_{\mathrm{Na^+}}=\pu{5,0 mS*m^2*mol-1}$&nbsp;; $\lambda_{\mathrm{HO^-}}=\pu{19,9 mS*m^2*mol-1}$&nbsp;; $\lambda_{\mathrm{CH_3COO^-}}=\pu{4,1 mS*m^2*mol-1}$.</p>
<p><b>Prévoir la courbe de titrage obtenue.</b></p>
</div>

<details class="nt-d nt-rep">
<summary><span class="nt-tag"><i class="fa-solid fa-key"></i>Réponse</span><span class="nt-sum">Voir le raisonnement</span></summary>
<div class="nt-d-body">
<p>La réaction support est $\ce{CH3COOH + HO^- -> CH3COO^- + H2O}$. L'acide éthanoïque, très peu dissocié, ne contribue presque pas à la conductivité&nbsp;:</p>
<div class="nt-scroll">
<table class="nt-t nt-t-pente">
<thead><tr><th></th><th>CH<sub>3</sub>COO<sup>−</sup></th><th>Na<sup>+</sup></th><th>HO<sup>−</sup></th><th>pente</th></tr></thead>
<tbody>
<tr><th>$V &lt; V_E$</th><td><span class="nt-ar nt-ar-up">↗</span></td><td><span class="nt-ar nt-ar-up">↗</span></td><td><span class="nt-ar nt-ar-eq">0</span></td><td><span class="nt-chip nt-chip-m">positive</span></td></tr>
<tr><th>$V &gt; V_E$</th><td><span class="nt-ar nt-ar-eq">=</span></td><td><span class="nt-ar nt-ar-up">↗</span></td><td><span class="nt-ar nt-ar-up">↗</span></td><td><span class="nt-chip nt-chip-f">nettement plus forte</span></td></tr>
</tbody>
</table>
</div>
<p><b>Avant l'équivalence</b>, chaque ion $\ce{HO^-}$ versé est consommé et remplacé par un ion $\ce{CH3COO^-}$, en plus de l'ion $\ce{Na+}$ apporté&nbsp;: la conductivité augmente, de $\lambda_{\mathrm{Na^+}} + \lambda_{\mathrm{CH_3COO^-}}$ par mole versée.</p>
<p><b>Après l'équivalence</b>, les ions $\ce{Na+}$ et $\ce{HO^-}$ s'accumulent&nbsp;: la conductivité augmente plus vite, de $\lambda_{\mathrm{Na^+}} + \lambda_{\mathrm{HO^-}}$ par mole versée, car l'ion hydroxyde conduit très bien. L'équivalence se repère à l'augmentation brusque de la pente.</p>
</div>
</details>

<details class="nt-d nt-plus">
<summary><span class="nt-tag"><i class="fa-solid fa-rocket"></i>Pour aller plus loin</span><span class="nt-sum">Une autre unité de conductivité molaire ionique</span></summary>
<div class="nt-d-body">
<p>On trouve parfois les conductivités molaires ioniques exprimées en $\pu{mS*cm-1*L*mol-1}$, plus commode quand les conductivités sont lues en $\pu{mS*cm-1}$ et les concentrations exprimées en $\pu{mol*L-1}$. La conversion est simple&nbsp;: $\pu{1 mS*m^2*mol-1} = \pu{10 mS*cm-1*L*mol-1}$.</p>
</div>
</details>

## Densité d'une solution et titre massique {.nt-h2}

<div class="nt-grid">
<div class="nt-f" style="margin:0 auto;">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Densité $d$ d'une solution</p>
<p class="nt-f-math">$$d=\frac{\rho_\text{solution}}{\rho_\text{eau}}$$</p>
<div class="nt-f-units"><span>Unité&nbsp;? <span class="nt-hole">aucune&nbsp;: c'est un rapport de deux masses volumiques</span></span></div>
</div>
<div class="nt-f" style="margin:0 auto;">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Titre massique $w$ d'un soluté</p>
<p class="nt-f-math">$$w=\frac{m_\text{soluté}}{m_\text{solution}}$$</p>
<div class="nt-f-units"><span>Unité&nbsp;? <span class="nt-hole">aucune&nbsp;: c'est un rapport de deux masses</span></span></div>
</div>
</div>

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Définition</p>
<p>Le <span class="imp">titre massique $w$</span> d'un soluté est le quotient de la masse de soluté apporté par la masse de solution.</p>
<p>On exprime souvent le titre en pourcentage. On l'appelle d'ailleurs parfois pourcentage massique mais il peut aussi être appelé teneur massique.</p>
</div>

<div class="nt-b nt-warn">
<p class="nt-tag"><i class="fa-solid fa-triangle-exclamation"></i>Attention</p>
<p>Le titre massique est souvent présenté comme «&nbsp;la masse de soluté pour 100&nbsp;g de solution&nbsp;», mais ce n'est pas une masse&nbsp;: c'est un nombre sans unité. «&nbsp;37&nbsp;%&nbsp;» signifie $w = 0{,}37$.</p>
</div>

<div class="nt-b nt-demo-box">
<p class="nt-tag"><i class="fa-solid fa-pen-nib"></i>Démonstration</p>
<p>Comment passer de l'étiquette d'un flacon ($w$ et $d$) à la concentration en quantité de matière $C$ du soluté&nbsp;? On raisonne sur un volume $V$ de solution&nbsp;:</p>
<p class="nt-center">$m_\text{solution} = \rho_\text{solution}\times V = d\times\rho_\text{eau}\times V \quad\text{et}\quad m_\text{soluté} = w\times m_\text{solution}$</p>
<p class="nt-center">$C = \dfrac{n}{V} = \dfrac{m_\text{soluté}}{M\times V} = \dfrac{w\times d\times\rho_\text{eau}}{M}$</p>
</div>

  /* ================= 3. Méthode des tangentes ================= */
  /* Toute la construction se fait dans les coordonnées de l'écran (comme sur la feuille de l'élève) :
     c'est là que « perpendiculaire » et « même longueur » ont un sens. */
  (function () {
    var root = document.getElementById('lab-tang');
    if (!root) { return; }
    var cv = $(root, 'canvas'), btn = $(root, '[data-act="next"]'), rst = $(root, '[data-act="reset"]'), msg = $(root, '.nt-msg'), S, step = 0, sys = 'ah';
    var NSTEP = 6;
    var MSG = [
      'Point de départ : la courbe pH = f(V) relevée. Cliquez sur « Étape suivante ».',
      '1. On trace à la règle une tangente T\u2081 à la courbe, dans la partie arrondie (le « coude ») située juste avant le saut de pH.',
      '2. On trace une droite T\u2082 parallèle à T\u2081 et tangente à la courbe dans le coude situé juste après le saut. En pratique : on pose l\u2019équerre contre T\u2081, la règle contre l\u2019équerre, puis on fait glisser l\u2019équerre le long de la règle jusqu\u2019à toucher la courbe de l\u2019autre côté du saut.',
      '3. Avec l\u2019équerre, on trace un segment perpendiculaire aux deux tangentes : il coupe T\u2081 en A et T\u2082 en B.',
      '4. On mesure AB à la règle et on place le milieu M du segment [AB] : AM = MB.',
      '5. On trace la droite parallèle à T\u2081 et T\u2082 passant par M (même technique qu\u2019à l\u2019étape 2) : elle est à égale distance des deux tangentes.',
      '6. Cette droite coupe la courbe au point d\u2019équivalence E : on lit V\u2091 en abscisse et pH\u2091 en ordonnée.'

    function P(V) { return pH(sys, V); }
    function dP(V) { return (P(V + 0.005) - P(V - 0.005)) / 0.01; }
    function geom(F) {
      var VE = C0 * V0 / CT, V1 = 0.85 * VE, m = dP(V1), V2 = VE + 0.2;
      /* après le saut, la pente (en valeur absolue) décroît : on cherche le point où elle redevient égale à celle de T1 */
      while (V2 < 20 && Math.abs(dP(V2)) > Math.abs(m)) { V2 += 0.005; }
      var T1 = { x: F.X(V1), y: F.Y(P(V1)) }, T2 = { x: F.X(V2), y: F.Y(P(V2)) };
      var dx = F.X(1) - F.X(0), dy = F.Y(m) - F.Y(0), n = Math.hypot(dx, dy), u = { x: dx / n, y: dy / n }, nv = { x: -u.y, y: u.x };
      /* A : un point de T1 à gauche du point de contact ; B : intersection de la perpendiculaire en A avec T2 */
      var A = { x: T1.x - 0.22 * (F.R - F.L) * u.x, y: T1.y - 0.22 * (F.R - F.L) * u.y };
      var t = ((T2.x - A.x) * nv.x + (T2.y - A.y) * nv.y);
      var B = { x: A.x + t * nv.x, y: A.y + t * nv.y }, M = { x: (A.x + B.x) / 2, y: (A.y + B.y) / 2 };
      /* E : intersection de la droite médiane avec la courbe (distance signée nulle) */
      function dist(V) { var px = F.X(V), py = F.Y(P(V)); return (px - M.x) * nv.x + (py - M.y) * nv.y; }
      var lo = V1, hi = V2, s0 = dist(lo);
      for (var i = 0; i < 60; i++) { var mid = (lo + hi) / 2; if (dist(mid) * s0 > 0) { lo = mid; } else { hi = mid; } }
      var VEf = (lo + hi) / 2;
      return { u: u, nv: nv, T1: T1, T2: T2, A: A, B: B, M: M, VE: VEf, pE: P(VEf) };
    }
    function line(c, F, p, u, color, dash, w) {
      var L = 3000; c.strokeStyle = color; c.lineWidth = w || 2; c.setLineDash(dash || []);
      c.beginPath(); c.moveTo(p.x - L * u.x, p.y - L * u.y); c.lineTo(p.x + L * u.x, p.y + L * u.y); c.stroke(); c.setLineDash([]);
    }
    function dot(c, p, color, r) { c.fillStyle = color; c.beginPath(); c.arc(p.x, p.y, r || 5, 0, 2 * Math.PI); c.fill(); }
    function label(c, p, txt, color, ox, oy) { c.fillStyle = color; c.font = '700 13px system-ui, sans-serif'; c.textAlign = 'center'; c.fillText(txt, p.x + ox, p.y + oy); }
    function rightAngle(c, p, a, b, color) {   /* petit carré en p, côtés selon les directions a et b */
      var k = 9; c.strokeStyle = color; c.lineWidth = 1.5; c.beginPath();
      c.moveTo(p.x + k * a.x, p.y + k * a.y); c.lineTo(p.x + k * a.x + k * b.x, p.y + k * a.y + k * b.y); c.lineTo(p.x + k * b.x, p.y + k * b.y); c.stroke();
    }
    function tick(c, p, u, color) { var k = 7; c.strokeStyle = color; c.lineWidth = 2.2; c.beginPath(); c.moveTo(p.x - k * u.x, p.y - k * u.y); c.lineTo(p.x + k * u.x, p.y + k * u.y); c.stroke(); }
    function draw() {
      var c = S.ctx, w = S.w, h = S.h; c.clearRect(0, 0, w, h);
      var F = frame(c, w, h, { x0: 0, x1: 20, dx: 2, y0: 0, y1: 14, dy: 2, xl: 'volume de solution titrante versé V (mL)', yl: 'pH' });
      curve(c, F, P, 0, 20, 500, col('--blue'));
      var g = geom(F), R = col('--rose'), G = col('--emerald'), K = col('--ink');
      /* sens de AB : de A vers B */
      var ab = { x: g.B.x - g.A.x, y: g.B.y - g.A.y }, nab = Math.hypot(ab.x, ab.y); ab.x /= nab; ab.y /= nab;
      c.save(); c.beginPath(); c.rect(F.L, F.T, F.R - F.L, F.B - F.T); c.clip();
      if (step >= 1) { line(c, F, g.T1, g.u, R); dot(c, g.T1, R); }
      if (step >= 2) { line(c, F, g.T2, g.u, R); dot(c, g.T2, R); }
      if (step >= 3) {
        c.strokeStyle = K; c.lineWidth = 1.6; c.beginPath(); c.moveTo(g.A.x, g.A.y); c.lineTo(g.B.x, g.B.y); c.stroke();
        rightAngle(c, g.A, g.u, ab, K); rightAngle(c, g.B, g.u, { x: -ab.x, y: -ab.y }, K);
      }
      if (step >= 4) {
        dot(c, g.M, G, 5);
        tick(c, { x: (g.A.x + g.M.x) / 2, y: (g.A.y + g.M.y) / 2 }, g.u, G);
        tick(c, { x: (g.M.x + g.B.x) / 2, y: (g.M.y + g.B.y) / 2 }, g.u, G);
      }
      if (step >= 5) { line(c, F, g.M, g.u, G, [8, 5], 2.2); }
      c.restore();
      if (step >= 1) { label(c, { x: g.T1.x, y: g.T1.y }, 'T\u2081', R, 0, 22); }
      if (step >= 2) { label(c, { x: g.T2.x, y: g.T2.y }, 'T\u2082', R, 0, -12); }
      if (step >= 3) { label(c, g.A, 'A', K, -12 * ab.x - 10 * g.u.x, -12 * ab.y + 4); label(c, g.B, 'B', K, 12 * ab.x - 10 * g.u.x, 12 * ab.y + 4); }
      if (step >= 4) { label(c, g.M, 'M', G, -26 * g.u.x - 6, -26 * g.u.y + 5); }
      if (step >= 6) {
        var E = { x: F.X(g.VE), y: F.Y(g.pE) };
        c.strokeStyle = col('--amber'); c.setLineDash([4, 4]); c.lineWidth = 1.5;
        c.beginPath(); c.moveTo(E.x, E.y); c.lineTo(E.x, F.B); c.moveTo(E.x, E.y); c.lineTo(F.L, E.y); c.stroke(); c.setLineDash([]);
        dot(c, E, col('--amber'), 7);
        c.fillStyle = col('--amber'); c.font = '700 13px system-ui, sans-serif'; c.textAlign = 'left'; c.fillText('E', E.x + 10, E.y - 6);
        c.textAlign = 'center'; c.fillText('V\u2091 = ' + fr(g.VE, 1) + ' mL', E.x, F.B - 6);
        c.textAlign = 'left'; c.fillText('pH\u2091 = ' + fr(g.pE, 1), F.L + 4, E.y - 6);
      }
      msg.textContent = MSG[step];
      btn.disabled = step >= NSTEP;
    }
    btn.addEventListener('click', function () { if (step < NSTEP) { step++; draw(); } });
    rst.addEventListener('click', function () { step = 0; draw(); });

  /* ================= 4. Titrage conductimétrique ================= */
  (function () {
    var root = document.getElementById('lab-cond');
    if (!root) { return; }
    var cv = $(root, 'canvas'), cbW = $(root, '[data-p="eau"]'), cbL = $(root, '[data-p="droites"]'), oV = $(root, '.out-ve'), msg = $(root, '.nt-msg'), S, sys = 'nacl';
    /* conductivités molaires ioniques (mS·m²·mol⁻¹) */
    var LAM = { Na: 5.0, Cl: 7.6, Ag: 6.2, NO3: 7.1, H: 35.0, HO: 19.9, Ac: 4.1 };
    var Vt0 = 20, Ctr = 0.020, C0t = 0.010;    /* V_E = 10 mL */
    var NAMES = { nacl: 'Cl\u207b titrés par Ag\u207a (précipitation de AgCl)', ac: 'CH\u2083COOH titré par la soude', hcl: 'HCl titré par la soude' };
    function sigma(V) {
      var n0 = C0t * Vt0, nt = Ctr * V, Vt = (Vt0 + V + (cbW.checked ? 200 : 0)) * 1e-6, s = 0, before = nt < n0;   /* mmol, m³ */
      function add(lam, n) { s += lam * (n * 1e-3) / Vt; }   /* mS/m */
      if (sys === 'nacl') { add(LAM.Na, n0); add(LAM.Cl, Math.max(0, n0 - nt)); add(LAM.Ag, Math.max(0, nt - n0)); add(LAM.NO3, nt); }
      else if (sys === 'ac') { add(LAM.Ac, Math.min(nt, n0)); add(LAM.Na, nt); add(LAM.HO, Math.max(0, nt - n0)); }
      else { add(LAM.H, Math.max(0, n0 - nt)); add(LAM.Cl, n0); add(LAM.Na, nt); add(LAM.HO, Math.max(0, nt - n0)); }
      return s / 100;   /* mS/cm */
    }
    function fit(P) {
      var n = P.length, sx = 0, sy = 0, sxx = 0, sxy = 0;
      P.forEach(function (p) { sx += p[0]; sy += p[1]; sxx += p[0] * p[0]; sxy += p[0] * p[1]; });
      var a = (n * sxy - sx * sy) / (n * sxx - sx * sx); return [a, (sy - a * sx) / n];
    }
    function draw() {
      var P = [];
      for (var V = 0; V <= 20; V += 1) { P.push([V, sigma(V) * (1 + 0.005 * Math.sin(V * 7.3))]); }
      var ymax = Math.max.apply(null, P.map(function (p) { return p[1]; })) * 1.15;
      var step = ymax > 2 ? 0.5 : (ymax > 0.8 ? 0.2 : (ymax > 0.3 ? 0.1 : 0.02));

      if (cbL.checked) {
        var a = P.filter(function (p) { return p[0] <= 7; }), b = P.filter(function (p) { return p[0] >= 13; });

        curve(c, F, function (x) { return f1[0] * x + f1[1]; }, 0, 20, 2, col('--rose'), 2, [6, 4]);
        curve(c, F, function (x) { return f2[0] * x + f2[1]; }, 0, 20, 2, col('--rose'), 2, [6, 4]);
        c.restore();
        c.fillStyle = col('--amber'); c.beginPath(); c.arc(F.X(Ve), F.Y(sE), 6, 0, 2 * Math.PI); c.fill();
        c.strokeStyle = col('--amber'); c.setLineDash([4, 4]); c.beginPath(); c.moveTo(F.X(Ve), F.Y(sE)); c.lineTo(F.X(Ve), F.B); c.stroke(); c.setLineDash([]);
        c.font = '700 12px system-ui, sans-serif'; c.textAlign = 'center'; c.fillText('V\u2091', F.X(Ve), F.B - 6);
        oV.textContent = fr(Ve, 2) + ' mL (valeur exacte : 10,00 mL)';
      } else { oV.textContent = '\u2014'; }
      P.forEach(function (p) {
        var near = cbL.checked && p[0] > 7 && p[0] < 13;
        c.strokeStyle = near ? col('--muted') : col('--blue'); c.lineWidth = 2.2;
        var x = F.X(p[0]), y = F.Y(p[1]);

      });

    }
