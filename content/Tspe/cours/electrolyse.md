<p class="nt-lead">Forcer le sens d'évolution d'un système&nbsp;: c'est ce que fait l'électrolyse, l'opération inverse de la pile.</p>

## Évolution forcée {.nt-h2}

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Définition</p>
<p>Lors d'une <span class="imp nt-hole">évolution forcée</span>, un système chimique évolue dans le <span class="imp nt-hole">sens inverse</span> de son évolution spontanée. Le quotient de réaction <span class="imp nt-hole">s'éloigne</span> alors de la constante d'équilibre.</p>
</div>

<p class="nt-cap">Pour un même système, selon la position du quotient de réaction initial par rapport à $K(T)$, l'évolution spontanée rapproche $Q_r$ de $K$&nbsp;; une évolution forcée l'en éloigne, ce qui exige un apport d'énergie extérieur.</p>

## Électrolyse {.nt-h2}

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Définition</p>
<p>Dans le cas d'une oxydoréduction, on peut forcer le sens d'évolution d'un système en <span class="imp nt-hole">imposant le sens du courant électrique</span> grâce à un générateur. La transformation s'appelle alors une <span class="imp nt-hole">électrolyse</span>.</p>
</div>

<div class="nt-b nt-prop">
<p class="nt-tag"><i class="fa-solid fa-star"></i>À retenir</p>
<p>L'électrolyse est une conversion d'<span class="imp nt-hole">énergie électrique</span> en <span class="imp nt-hole">énergie chimique</span>&nbsp;: c'est l'inverse d'une pile.</p>
</div>

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>L'électrolyseur</p>
<p>On réalise une électrolyse grâce à un <span class="imp">électrolyseur</span>, constitué de deux <span class="imp nt-hole">électrodes</span> plongeant dans un <span class="imp nt-hole">électrolyte</span> (solution ionique) et reliées à un <span class="imp nt-hole">générateur de courant continu</span>, qui impose le sens de déplacement des électrons.</p>
<ul class="nt-facts">
<li>L'électrode où se déroule la <b style="color:#E11D48;"><u>r</u>éduction</b> est la <b style="color:#E11D48;"><u>c</u>athode</b>. Elle est reliée à la borne <span class="imp nt-hole">$\ominus$</span> du générateur, qui lui fournit des électrons.</li>
<li>L'électrode où se déroule l'<b style="color:#2A6BC4;"><u>o</u>xydation</b> est l'<b style="color:#2A6BC4;"><u>a</u>node</b>. Elle est reliée à la borne <span class="imp nt-hole" style="color:#E11D48;">$\oplus$</span> du générateur, qui lui prend des électrons.</li>
</ul>
</div>

## Étude quantitative {.nt-h2}

<p class="nt-lead">Pendant une durée $\Delta t$, le générateur de courant continu délivre un courant d'intensité $I$. La charge électrique transférée peut s'écrire de deux façons&nbsp;:</p>

<div class="nt-grid">
<div class="nt-f" style="margin:0 auto;">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Charge et intensité</p>
<p class="nt-f-math">$$Q = I\times \Delta t$$</p>
<div class="nt-f-units"><span>$Q$ en <b>C</b>, $I$ en <b>A</b>, $\Delta t$ en <b>s</b></span></div>
</div>
<div class="nt-f" style="margin:0 auto;">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Charge et quantité d'électrons</p>
<p class="nt-f-math">$$Q = n(\mathrm{e^-})\times N_\mathrm{A}\times e=n(\mathrm{e^-})\times \mathcal{F}$$</p>
<div class="nt-f-units"><span>$n(\mathrm{e^-})$ en <b>mol</b></span><span>$e = \pu{1,60E-19 C}$, $N_\mathrm{A} = \pu{6,02E23 mol-1}$</span><span>$\mathcal{F}=$ <b>$\pu{9,65E4 C*mol-1}$</b></span></div>
</div>
</div>

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-list-check"></i>Méthode&nbsp;: de l'intensité à la quantité de produit</p>
<ol class="nt-steps">
<li><p>Calculer la charge transférée&nbsp;: $Q = I\times\Delta t$.</p></li>
<li><p>En déduire la quantité d'électrons échangés&nbsp;: $n(\mathrm{e^-}) = \dfrac{Q}{\mathcal{F}}$.</p></li>
<li><p>Utiliser la demi-équation de l'électrode pour relier $n(\mathrm{e^-})$ à la quantité de produit formé (par exemple, $\mathrm{Cu^{2+}} + 2\,\mathrm{e^-} \rightarrow \mathrm{Cu}$ donne $n(\mathrm{Cu}) = n(\mathrm{e^-})/2$).</p></li>
<li><p>Convertir en masse ($m = n\times M$) ou en volume de gaz ($V = n\times V_\mathrm{m}$).</p></li>
</ol>
</div>

## Exemple 1&nbsp;: électrolyse de l'eau {.nt-h2}

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-droplet"></i>Les réactions aux électrodes (en milieu acide)</p>
<ul class="nt-facts">
<li>à la <b style="color:#E11D48;">cathode</b> (réduction)&nbsp;: $\ce{2 H+ + 2 e- -> H2}$&nbsp;;</li>
<li>à l'<b style="color:#2A6BC4;">anode</b> (oxydation)&nbsp;: $\ce{2 H2O -> O2 + 4 H+ + 4 e-}$.</li>
</ul>
<p>Bilan&nbsp;: $\ce{2 H2O -> 2 H2 + O2}$. Cette réaction est l'inverse de celle qui a lieu, spontanément, dans une pile à hydrogène.</p>
</div>

<p class="nt-cap">Pour 4 électrons échangés, il se forme 2 molécules de dihydrogène et une seule de dioxygène&nbsp;: le volume de dihydrogène recueilli est le double de celui de dioxygène.</p>

<div class="nt-b nt-ask">
<p class="nt-tag"><i class="fa-solid fa-circle-question"></i>Exercice</p>
<p>On électrolyse de l'eau acidifiée pendant 10&nbsp;minutes, avec un courant d'intensité $I = \pu{1,0 A}$. Quels volumes de dihydrogène et de dioxygène recueille-t-on&nbsp;? On prendra $V_\mathrm{m} = \pu{24 L*mol-1}$.</p>
</div>

<details class="nt-d nt-rep">
<summary><span class="nt-tag"><i class="fa-solid fa-key"></i>Réponse</span><span class="nt-sum">Voir la résolution</span></summary>
<div class="nt-d-body">
<ol class="nt-steps">
<li><p>$Q = I\times\Delta t = 1{,}0\times 600 = \pu{6,0E2 C}$.</p></li>
<li><p>$n(\mathrm{e^-}) = \dfrac{Q}{\mathcal{F}} = \dfrac{6{,}0\times10^{2}}{9{,}65\times10^{4}} = \pu{6,2E-3 mol}$.</p></li>
<li><p>À la cathode, 2 électrons donnent une molécule de $\ce{H2}$&nbsp;: $n(\ce{H2}) = \dfrac{n(\mathrm{e^-})}{2} = \pu{3,1E-3 mol}$, soit $V(\ce{H2}) = n\times V_\mathrm{m} = \pu{7,5E-2 L} = \pu{75 mL}$.</p></li>
<li><p>À l'anode, 4 électrons libèrent une molécule de $\ce{O2}$&nbsp;: $n(\ce{O2}) = \dfrac{n(\mathrm{e^-})}{4} = \pu{1,6E-3 mol}$, soit $V(\ce{O2}) \approx \pu{37 mL}$, bien la moitié du volume de dihydrogène.</p></li>
</ol>
</div>
</details>

<details class="nt-d nt-plus">
<summary><span class="nt-tag"><i class="fa-solid fa-rocket"></i>Pour aller plus loin</span><span class="nt-sum">L'hydrogène, une façon de stocker l'électricité</span></summary>
<div class="nt-d-body">
<p>Aujourd'hui, l'essentiel du dihydrogène est produit à partir de gaz naturel, en émettant du dioxyde de carbone. Produit par électrolyse de l'eau avec de l'électricité renouvelable, il devient un moyen de stocker cette électricité sous forme chimique, que l'on récupère ensuite dans une pile à combustible. Le rendement de l'aller-retour reste toutefois modeste&nbsp;: une grande partie de l'énergie est perdue sous forme de chaleur.</p>

## Exemple 2&nbsp;: cuivrage d'un métal {.nt-h2}

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-coins"></i>Le principe</p>
<p>Pour recouvrir un objet métallique d'une fine couche de cuivre, on le relie à la borne $\ominus$ du générateur&nbsp;: il devient la <b style="color:#E11D48;">cathode</b>, où les ions cuivre de l'électrolyte sont réduits et se déposent. Une plaque de cuivre, reliée à la borne $\oplus$, sert d'<b style="color:#2A6BC4;">anode</b>&nbsp;: elle est oxydée et renouvelle les ions $\mathrm{Cu^{2+}}$ de la solution. C'est le principe de la galvanoplastie, qui sert aussi à dorer, argenter ou chromer des objets.</p>
</div>

<div class="nt-d-body">
<ul class="nt-facts">

  function fr(x, nd) { return x.toFixed(nd).replace('.', ',').replace('-', '\u2212'); }
  function sci(x, nd) {
    if (x === 0) { return '0'; }
    var n = Math.floor(Math.log10(Math.abs(x)) + 1e-9), a = x / Math.pow(10, n), t = a.toFixed(nd);
    if (Math.abs(parseFloat(t)) >= 10) { n += 1; t = (a / 10).toFixed(nd); }
    if (n === 0) { return t.replace('.', ','); }
    return t.replace('.', ',') + ' \u00d7 10<sup>' + String(n).replace('-', '\u2212') + '</sup>';
  }

  function along(pts, s) {
    var L = 0, seg = [];
    for (var i = 0; i + 1 < pts.length; i++) { var d = Math.hypot(pts[i + 1][0] - pts[i][0], pts[i + 1][1] - pts[i][1]); seg.push(d); L += d; }
    var target = ((s % 1) + 1) % 1 * L;
    for (i = 0; i < seg.length; i++) {
      if (target <= seg[i]) { var u = target / seg[i]; return [pts[i][0] + (pts[i + 1][0] - pts[i][0]) * u, pts[i][1] + (pts[i + 1][1] - pts[i][1]) * u, (pts[i + 1][0] - pts[i][0]) / seg[i], (pts[i + 1][1] - pts[i][1]) / seg[i]]; }
      target -= seg[i];
    }
    return [pts[pts.length - 1][0], pts[pts.length - 1][1], 1, 0];
  }

  }
