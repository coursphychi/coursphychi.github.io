## Les solutions {.nt-h2}


<div class="nt-b nt-ask">
<p class="nt-tag"><i class="fa-solid fa-circle-question"></i>Question</p>
<p>L'étiquette d'une eau minérale indique que cette eau contient des «&nbsp;minéraux&nbsp;» (calcium, magnésium, sodium…). Pourtant, l'eau est parfaitement limpide. Où sont ces minéraux&nbsp;?</p>
</div>

<details class="nt-d nt-rep">
<summary><span class="nt-tag"><i class="fa-solid fa-key"></i>Réponse</span><span class="nt-sum">Voir la réponse</span></summary>
<div class="nt-d-body">
<p>Ils sont <b>dissous</b> dans l'eau, sous forme d'ions&nbsp;: on ne peut plus les distinguer. L'eau minérale est une solution.</p>
</div>
</details>

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Solution aqueuse</p>
<p>Une <span class="imp">solution aqueuse</span> est un <span class="imp nt-hole">mélange homogène</span> dans lequel l'eau est le constituant <span class="imp nt-hole">ultra-majoritaire</span>. Elle y joue le rôle de <span class="imp nt-hole">solvant</span>&nbsp;; les espèces chimiques dissoutes sont qualifiées de <span class="imp nt-hole">solutés</span>.</p>
</div>

<div class="nt-b nt-ex">
<p class="nt-tag"><i class="fa-solid fa-lightbulb"></i>Exemples</p>
<ul class="nt-facts">
<li>Le vinaigre est, en première approximation, une solution aqueuse d'acide éthanoïque (le soluté).</li>
<li>Le soluté peut être dissous sous forme de <b>molécules</b>&nbsp;: les molécules de saccharose $\ce{C12H22O11}$ dans une eau sucrée.</li>
<li>Il peut aussi être dissous sous forme d'<b>ions</b>&nbsp;: les ions sodium $\ce{Na+}$ et chlorure $\ce{Cl-}$ dans une eau salée.</li>
</ul>
</div>

<div class="nt-b nt-demo-box">
<p class="nt-tag"><i class="fa-solid fa-eye"></i>Remarque</p>
<p>La <b>dissolution</b> est l'opération qui consiste à dissoudre un soluté dans un solvant. Le solvant n'est pas toujours l'eau&nbsp;: l'éthanol, par exemple, sert de solvant dans les parfums.</p>
</div>

<div class="nt-b nt-ask">
<p class="nt-tag"><i class="fa-solid fa-circle-question"></i>Question</p>
<p>Même soluté, même solvant&nbsp;: qu'est-ce qui change d'une solution à l'autre&nbsp;? Et qu'arrive-t-il à la dernière&nbsp;?</p>
</div>

<details class="nt-d nt-rep">
<summary><span class="nt-tag"><i class="fa-solid fa-key"></i>Réponse</span><span class="nt-sum">Voir la réponse</span></summary>
<div class="nt-d-body">
<p>C'est la <b>quantité de soluté dissous</b> dans un même volume de solution qui change&nbsp;: plus il y en a, plus la solution est foncée. Dans la dernière, on a ajouté trop de sulfate de cuivre&nbsp;: une partie ne se dissout plus et reste au fond. La solution est <b>saturée</b> (voir plus bas).</p>
</div>
</details>

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Concentration en masse</p>
<p>La <span class="imp">concentration en masse</span> $C_m$ d'un soluté est la <span class="imp nt-hole">masse</span> de cette espèce chimique dissoute <span class="imp nt-hole">par litre de solution</span>. Elle peut s'exprimer en <span class="imp nt-hole">g/L</span>.</p>
</div>

<div class="nt-f">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Concentration en masse</p>
<p class="nt-f-math">$$C_m = \frac{m_\text{soluté}}{V_\text{solution}}$$</p>
<div class="nt-f-units"><span>$C_m$ en <b>g/L</b></span><span>$m_\text{soluté}$ en <b>g</b></span><span>$V_\text{solution}$ en <b>L</b></span></div>
</div>

<div class="nt-b nt-ex">
<p class="nt-tag"><i class="fa-solid fa-lightbulb"></i>Exemple</p>
<p>Une solution de chlorure de sodium de concentration en masse 10&nbsp;g/L est obtenue en introduisant 10&nbsp;g de chlorure de sodium dans une fiole jaugée de 1,0&nbsp;L, et en ajoutant de l'eau jusqu'à obtenir un volume final de mélange égal à 1,0&nbsp;L.</p>
</div>

<div class="nt-grid">
<div class="nt-f" style="margin:0 auto;">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Pour trouver la masse</p>
<p class="nt-f-math">$$m = C_m \times V$$</p>
</div>
<div class="nt-f" style="margin:0 auto;">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Pour trouver le volume</p>
<p class="nt-f-math">$$V = \frac{m}{C_m}$$</p>
</div>
</div>

<div class="nt-b nt-warn">
<p class="nt-tag"><i class="fa-solid fa-triangle-exclamation"></i>Attention aux unités</p>
<ul class="nt-facts">
<li>Le volume doit être en <b>litres</b>&nbsp;: 500&nbsp;mL = 0,500&nbsp;L&nbsp;; 1&nbsp;m³ = 1&nbsp;000&nbsp;L.</li>
<li>Pour les très faibles concentrations, on utilise le <b>mg/L</b>&nbsp;: 2&nbsp;mg/L = 0,002&nbsp;g/L.</li>
</ul>
</div>

<div class="nt-b nt-ask">
<p class="nt-tag"><i class="fa-solid fa-circle-question"></i>Exercice 1</p>
<p>On dissout 25&nbsp;g de sucre dans de l'eau, de façon à obtenir 500&nbsp;mL de solution. Que vaut la concentration en masse du sucre&nbsp;?</p>
</div>

<details class="nt-d nt-rep">
<summary><span class="nt-tag"><i class="fa-solid fa-key"></i>Réponse</span><span class="nt-sum">Voir la résolution</span></summary>
<div class="nt-d-body">
<p>Données&nbsp;: $m$ = 25&nbsp;g, $V$ = 500&nbsp;mL = 0,500&nbsp;L. On cherche $C_m$.</p>
<p class="nt-center">$C_m = \dfrac{m}{V} = \dfrac{25}{0{,}500} = 50$&nbsp;g/L</p>
</div>
</details>

<div class="nt-b nt-ask">
<p class="nt-tag"><i class="fa-solid fa-circle-question"></i>Exercice 2</p>
<p>Une piscine de 50&nbsp;m³ doit contenir des ions hypochlorite $\ce{ClO-}$ à une concentration en masse de 2,0&nbsp;mg/L. Quelle masse d'ions hypochlorite doit-on verser dans la piscine&nbsp;? On suppose que l'ajout du soluté ne modifie pas le volume de la piscine.</p>
</div>

<details class="nt-d nt-rep">
<summary><span class="nt-tag"><i class="fa-solid fa-key"></i>Réponse</span><span class="nt-sum">Voir la résolution</span></summary>
<div class="nt-d-body">
<p>Données&nbsp;: $V$ = 50&nbsp;m³ = 50&nbsp;000&nbsp;L&nbsp;; $C_m$ = 2,0&nbsp;mg/L = 0,0020&nbsp;g/L. On cherche $m$.</p>
<p class="nt-center">$m = C_m \times V = 0{,}0020 \times 50\,000 = 100$&nbsp;g, soit 0,10&nbsp;kg.</p>
</div>
</details>

<div class="nt-b nt-warn">
<p class="nt-tag"><i class="fa-solid fa-triangle-exclamation"></i>Piège&nbsp;: concentration en masse et masse volumique</p>
<p>Une masse volumique est aussi une masse divisée par un volume, mais ce n'est <b>pas la même masse</b>&nbsp;!</p>
<ul class="nt-facts">
<li>Concentration en masse&nbsp;: $C_m = \dfrac{m_\text{soluté}}{V_\text{solution}}$, la masse du <b>soluté</b> seul.</li>
<li>Masse volumique de la solution&nbsp;: $\rho = \dfrac{m_\text{solution}}{V_\text{solution}}$, la masse de <b>toute la solution</b> (solvant compris).</li>
</ul>
<p>Par exemple, l'eau de mer contient environ 35&nbsp;g/L de sel, mais sa masse volumique vaut environ 1&nbsp;025&nbsp;g/L.</p>
</div>

## Concentration maximale et saturation {.nt-h2}

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Concentration maximale d'un soluté</p>
<p>La <span class="imp">concentration maximale</span> d'un soluté est la <span class="imp nt-hole">masse maximale</span> de cette espèce chimique qui peut être dissoute <span class="imp nt-hole">par litre de solution</span>.</p>
<p>La solution est alors dite <span class="imp nt-hole">saturée</span>&nbsp;: si on ajoute encore du soluté, il se dépose au fond sans se dissoudre.</p>
</div>

<details class="nt-d nt-rep">

<p>À 25&nbsp;°C, on peut dissoudre au maximum 1,0&nbsp;g d'aspirine dans 300&nbsp;mL de solution. On prépare 400&nbsp;mL de solution à partir de 1,20&nbsp;g d'aspirine pure.</p>
<ol class="nt-steps">
<li><p>Peut-on dissoudre toute l'aspirine&nbsp;?</p></li>
<li><p>Quelle masse maximale d'aspirine peut-on dissoudre dans ces 400&nbsp;mL&nbsp;?</p></li>

## Diluer une solution {.nt-h2}

<div class="nt-b nt-prop">
<p class="nt-tag"><i class="fa-solid fa-star"></i>À retenir</p>
<p>Pour <b>diminuer</b> la concentration d'une solution, on <span class="imp nt-hole">ajoute du solvant</span>&nbsp;: on <span class="imp nt-hole">dilue</span>. On prélève un volume $V_\text{mère}$ de solution mère à la pipette jaugée, on le verse dans une fiole jaugée de volume $V_\text{fille}$, et on complète avec de l'eau distillée.</p>
</div>

<div class="nt-b nt-demo-box">
<p class="nt-tag"><i class="fa-solid fa-list-check"></i>Démonstration</p>
<p>Lors d'une dilution, on ne fait qu'ajouter de l'eau&nbsp;: la <b>masse de soluté se conserve</b>. Donc&nbsp;:</p>
<p class="nt-center">$m_\text{fille} = m_\text{mère} \quad\Leftrightarrow\quad C_\text{fille}\times V_\text{fille} = C_\text{mère}\times V_\text{mère}$</p>
</div>

<div class="nt-f">
<p class="nt-tag"><i class="fa-solid fa-equals"></i>Facteur de dilution</p>
<p class="nt-f-math">$$F = \frac{C_\text{mère}}{C_\text{fille}} = \frac{V_\text{fille}}{V_\text{mère}} = \frac{V_\text{fiole}}{V_\text{pipette}}$$</p>
<div class="nt-f-units"><span>$F$, sans unité, est le nombre de fois que la solution est diluée&nbsp;: $F > 1$</span></div>
</div>

## Doser une espèce par étalonnage {.nt-h2}

<div class="nt-b nt-def">
<p class="nt-tag"><i class="fa-solid fa-book-open"></i>Dosage par étalonnage</p>
<p>Un <span class="imp">dosage par étalonnage</span> est une méthode de détermination d'une concentration, généralement non destructive, utilisant une courbe de référence liant la valeur d'une <span class="imp nt-hole">grandeur physique</span> (absorbance, conductivité, masse volumique…) à la <span class="imp nt-hole">concentration</span> d'un soluté.</p>
<p>Cette courbe de référence, appelée <span class="imp nt-hole">courbe d'étalonnage</span>, doit être monotone sur l'intervalle de concentration qui encadre la concentration inconnue. Elle n'est pas nécessairement une droite, mais une droite permet d'obtenir une précision constante, quelle que soit la concentration recherchée.</p>
</div>

<div class="nt-b nt-ex">
<p class="nt-tag"><i class="fa-solid fa-lightbulb"></i>Exemples</p>
<p>Dosage du chlorure de sodium dans du sérum physiologique par mesure de la conductance&nbsp;; dosage du sucre dans une boisson sucrée par mesure de la masse volumique&nbsp;; dosage des ions permanganate par mesure de l'absorbance.</p>
</div>

      var top = g.bt, bot = g.bb, k = (bot - top) / BUR, yl = top + (BUR - reste) * k, r = 9;
      /* verre */
      var gv = c.createLinearGradient(x - r, 0, x + r, 0); gv.addColorStop(0, 'rgba(203,213,225,.55)'); gv.addColorStop(0.35, 'rgba(255,255,255,.2)'); gv.addColorStop(1, 'rgba(203,213,225,.55)');
      c.fillStyle = gv; c.fillRect(x - r, top - 6, 2 * r, bot - top + 6);
      /* liquide, avec son ménisque */
      c.fillStyle = coul; c.beginPath(); c.moveTo(x - r + 1, yl - 2); c.quadraticCurveTo(x, yl + 4, x + r - 1, yl - 2); c.lineTo(x + r - 1, bot); c.lineTo(x + 3, bot + 12); c.lineTo(x - 3, bot + 12); c.lineTo(x - r + 1, bot); c.closePath(); c.fill();
      var gl = c.createLinearGradient(x - r, 0, x + r, 0); gl.addColorStop(0, 'rgba(255,255,255,0)'); gl.addColorStop(0.3, 'rgba(255,255,255,.45)'); gl.addColorStop(0.5, 'rgba(255,255,255,0)'); c.fillStyle = gl; c.fillRect(x - r, yl, 2 * r, bot - yl);
      /* parois : ouvertes en haut (léger évasement), cône vers le robinet */
      c.strokeStyle = '#64748B'; c.lineWidth = 1.4; c.lineJoin = 'round';
      c.beginPath(); c.moveTo(x - r - 3, top - 10); c.lineTo(x - r, top - 4); c.lineTo(x - r, bot); c.lineTo(x - 3, bot + 12); c.stroke();
      c.beginPath(); c.moveTo(x + r + 3, top - 10); c.lineTo(x + r, top - 4); c.lineTo(x + r, bot); c.lineTo(x + 3, bot + 12); c.stroke();
      /* graduations : traits courts tous les mL, longs tous les 5 mL, nombres tous les 10 mL */
      for (var v = 0; v <= BUR; v += 1) { var y = top + v * k, L = v % 10 === 0 ? 9 : (v % 5 === 0 ? 6 : 3); c.strokeStyle = 'rgba(30,41,59,.75)'; c.lineWidth = v % 5 === 0 ? 0.9 : 0.6; c.beginPath(); c.moveTo(x - r + 1, y); c.lineTo(x - r + 1 + L, y); c.stroke(); }
      c.fillStyle = '#334155'; c.font = '9.5px system-ui, sans-serif'; c.textAlign = 'left';
      [0, 10, 20, 30, 40, 50].forEach(function (v) { c.fillText(String(v), x + r + 4, top + v * k + 3.5); });
      /* robinet à clé et pointe effilée */
      c.fillStyle = coul; c.fillRect(x - 2, bot + 12, 4, 9);
      c.strokeStyle = '#64748B'; c.lineWidth = 1.2; c.beginPath(); c.moveTo(x - 3, bot + 12); c.lineTo(x - 3, bot + 21); c.moveTo(x + 3, bot + 12); c.lineTo(x + 3, bot + 21); c.stroke();
      var kg = c.createLinearGradient(0, bot + 14, 0, bot + 22); kg.addColorStop(0, '#60A5FA'); kg.addColorStop(1, '#1D4ED8');
      c.fillStyle = kg; rr(c, x - 7, bot + 14, 14, 8, 3); c.fill();
      c.fillStyle = '#1E3A8A'; rr(c, x + 6, bot + 15.5, 11, 5, 2.5); c.fill();
      c.fillStyle = coul; c.beginPath(); c.moveTo(x - 2.5, bot + 22); c.lineTo(x - 0.8, bot + 34); c.lineTo(x + 0.8, bot + 34); c.lineTo(x + 2.5, bot + 22); c.closePath(); c.fill();
      c.strokeStyle = '#64748B'; c.lineWidth = 1.1; c.beginPath(); c.moveTo(x - 2.5, bot + 22); c.lineTo(x - 0.8, bot + 34); c.lineTo(x + 0.8, bot + 34); c.lineTo(x + 2.5, bot + 22); c.stroke();
      txt(c, l1, x, 13, '#334155', '700 11px system-ui, sans-serif'); if (l2) { txt(c, l2, x, 26, '#64748B', '10.5px system-ui, sans-serif'); }
    }
    function draw() {
      if (!S) { return; }
      var c = S.ctx, g = geo(); c.clearRect(0, 0, g.w, g.h);
      burette(c, g, g.b1, Lm, couleur(C0), 'solution mère', '20,0 mg/L');
      burette(c, g, g.b2, Le, '#BFDBFE', 'eau distillée', '');   /* eau : bleu très pâle, pour voir son niveau */
      /* échelle : tubes préparés, emplacements vides, boisson */
      txt(c, 'échelle de teinte', g.r0 + g.slot * 3, g.yt - 14, '#475569', '600 11px system-ui, sans-serif');
      c.strokeStyle = '#CBD5E1'; c.lineWidth = 3; c.beginPath(); c.moveTo(g.r0 + 4, g.yt + 34); c.lineTo(g.r0 + g.slot * 7 - 4, g.yt + 34); c.stroke();   /* portoir */
      ECH.forEach(function (C, i) {
        if (i < faits.length) { tube(c, slotX(g, i), g.yt, g.tw, g.th, VT, couleur(C), null, C + ' mg/L'); }
        else { c.setLineDash([3, 3]); tube(c, slotX(g, i), g.yt, g.tw, g.th, 0, '', '#CBD5E1', C + ' mg/L', '#94A3B8'); c.setLineDash([]); }
      });
      if (faits.length === ECH.length) { tube(c, slotX(g, 6), g.yt, g.tw, g.th, VT, couleur(cx), '#E11D48', rep ? nb(cx) + ' mg/L' : 'boisson', '#E11D48'); }
      /* tube en cours de préparation */
      if (anim) {
        tube(c, anim.x, g.yt, g.tw, g.th, anim.vm + anim.ve, anim.vm + anim.ve > 0 ? couleur(C0 * anim.vm / (anim.vm + anim.ve)) : '', '#2563EB');
        if (anim.ph === 'pour1' || anim.ph === 'pour2') {
          var bxx = anim.ph === 'pour1' ? g.b1 : g.b2, ys = g.yt + g.th - Math.min(g.th - 6, (anim.vm + anim.ve) / 13 * g.th);
          c.strokeStyle = anim.ph === 'pour1' ? couleur(C0) : '#93C5FD'; c.lineWidth = 2; c.beginPath(); c.moveTo(bxx, g.bb + 34); c.lineTo(bxx, ys); c.stroke();
        }
      }
    }
    function question() {
      if (idx >= ECH.length) { return; }
      qEl.innerHTML = 'Tube ' + (idx + 1) + ' sur ' + ECH.length + '&nbsp;: préparer ' + fr(VT, 1) + '&nbsp;mL de solution à <b>' + ECH[idx] + '&nbsp;mg/L</b>. Quels volumes verser&nbsp;?';
      iM.value = ''; iE.value = ''; iM.disabled = iE.disabled = bP.disabled = false;
    }
    function mystere() {
      var i = Math.floor(Math.random() * (ECH.length - 1)); cx = Math.round((ECH[i] + 0.4 + Math.random() * 1.2) * 10) / 10; rep = false;
      bx.innerHTML = ''; bx.hidden = false; bNew.hidden = false;
      for (var k = 0; k < ECH.length - 1; k++) {
        (function (k) {
          var b = document.createElement('button'); b.type = 'button'; b.className = 'nt-btn'; b.textContent = 'entre ' + ECH[k] + ' et ' + ECH[k + 1] + ' mg/L';
          b.addEventListener('click', function () {
            if (rep) { return; } rep = true;
            var ok = cx > ECH[k] && cx < ECH[k + 1], lo = ECH.filter(function (e) { return e < cx; }).pop(), hi = ECH.filter(function (e) { return e > cx; })[0];
            if (ok) { b.classList.add('nt-btn-main'); } else { b.style.borderColor = '#E11D48'; b.style.color = '#E11D48'; }
            msg.innerHTML = (ok ? '<span style="color:#16A34A;">Bravo&nbsp;!</span> ' : '<span style="color:#E11D48;">Non.</span> ') + 'La teinte de la boisson est comprise entre celles des tubes à ' + lo + ' et ' + hi + '&nbsp;mg/L&nbsp;: sa concentration est comprise entre ' + lo + ' et ' + hi + '&nbsp;mg/L (ici, ' + nb(cx) + '&nbsp;mg/L). L\u2019échelle de teinte donne un <b>encadrement</b>, pas une valeur précise.';
            draw();
          });
          bx.appendChild(b);
        })(k);
      }
      qEl.innerHTML = 'L\u2019échelle de teinte est prête. Comparez la teinte de la boisson à celles des tubes, puis encadrez sa concentration en masse.';
      msg.textContent = '';
    }
    function start() {
      idx = 0; faits = []; good = 0; Lm = BUR; Le = BUR; anim = null; attente = null; rep = false; bx.hidden = true; bNew.hidden = true; prep.hidden = false; bOK.hidden = true; bP.hidden = false; sc.textContent = '0 / 0';
      msg.innerHTML = 'Chaque tube doit contenir ' + fr(VT, 1) + '&nbsp;mL au total. On prélève la solution mère avec la première burette, et on complète avec l\u2019eau distillée de la seconde.';
      question(); draw();
    }
    bP.addEventListener('click', function () {
      if (anim || idx >= ECH.length) { return; }
      var vm = num(iM.value), ve = num(iE.value), C = ECH[idx], VM = C * VT / C0, VE = VT - VM;
      if (isNaN(vm) || isNaN(ve)) { msg.textContent = 'Indiquez les deux volumes.'; return; }
      var ok = Math.abs(vm - VM) < 0.051 && Math.abs(ve - VE) < 0.051; if (ok) { good++; }
      sc.textContent = good + ' / ' + (idx + 1);
      var calc = 'La masse de colorant se conserve&nbsp;: C<sub>mère</sub> × V<sub>mère</sub> = C<sub>tube</sub> × V<sub>tube</sub>, donc V<sub>mère</sub> = ' + C + ' × ' + fr(VT, 1) + ' / ' + fr(C0, 1) + ' = <b>' + fr(VM, 1) + '&nbsp;mL</b> de solution mère, et V<sub>eau</sub> = ' + fr(VT, 1) + ' \u2212 ' + fr(VM, 1) + ' = <b>' + fr(VE, 1) + '&nbsp;mL</b> d\u2019eau.';
      msg.innerHTML = (ok ? '<span style="color:#16A34A;">Bravo&nbsp;!</span> ' : '<span style="color:#E11D48;">Non.</span> ') + calc;
      iM.disabled = iE.disabled = bP.disabled = true;
      if (ok) { lancer(VM, VE, C); }
      else { attente = [VM, VE, C]; bP.hidden = true; bOK.hidden = false; }   /* on laisse lire la correction avant de préparer le tube */
    });
    function lancer(VM, VE, C) { var g = geo(); anim = { ph: 'move1', t: 0, x: g.b1 - 60, x0: g.b1 - 60, VM: VM, VE: VE, vm: 0, ve: 0, C: C }; }
    bOK.addEventListener('click', function () { if (!attente || anim) { return; } bOK.hidden = true; bP.hidden = false; lancer(attente[0], attente[1], attente[2]); attente = null; });
    function step(dt) {
      if (!anim) { return; }
      var g = geo(), a = anim, D = 0.6, Q = RM ? 20 : 6;   /* durée des déplacements (s), débit des burettes (mL/s) */
      a.t += dt;
      function ease(u) { return u < 0.5 ? 2 * u * u : 1 - Math.pow(-2 * u + 2, 2) / 2; }
      if (a.ph === 'move1') { a.x = a.x0 + (g.b1 - a.x0) * ease(Math.min(1, a.t / D)); if (a.t >= D) { a.ph = 'pour1'; a.t = 0; } }
      else if (a.ph === 'pour1') { var d1 = Math.min(a.VM - a.vm, Q * dt); a.vm += d1; Lm -= d1; if (a.vm >= a.VM - 1e-9) { a.ph = 'move2'; a.t = 0; a.x0 = a.x; } }
      else if (a.ph === 'move2') { a.x = a.x0 + (g.b2 - a.x0) * ease(Math.min(1, a.t / D)); if (a.t >= D) { a.ph = 'pour2'; a.t = 0; } }
      else if (a.ph === 'pour2') { var d2 = Math.min(a.VE - a.ve, Q * dt); a.ve += d2; Le -= d2; if (a.ve >= a.VE - 1e-9) { a.ph = 'rack'; a.t = 0; a.x0 = a.x; } }
      else if (a.ph === 'rack') {
        var xt = slotX(g, idx); a.x = a.x0 + (xt - a.x0) * ease(Math.min(1, a.t / (D * 1.4)));
        if (a.t >= D * 1.4) { faits.push(a.C); idx++; anim = null; if (idx < ECH.length) { question(); } else { prep.hidden = true; mystere(); } }
      }
    }
    function loop(ts) { var dt = last === null ? 0 : Math.min(0.05, (ts - last) / 1000); last = ts; step(dt); draw(); requestAnimationFrame(loop); }
    bNew.addEventListener('click', function () { if (faits.length === ECH.length) { mystere(); draw(); } });
    $(root, '[data-act="restart"]').addEventListener('click', start);
    [iM, iE].forEach(function (x) { x.addEventListener('keydown', function (e) { if (e.key === 'Enter') { bP.click(); } }); });
    function setup() { S = canvasCtx(cv); draw(); }
    setup(); start(); onResize(setup); requestAnimationFrame(loop);
  })();

  /* ================= Dosage par étalonnage : le sucre d'une boisson, par la masse volumique ================= */
  (function () {
